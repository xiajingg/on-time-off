# 按时下班 · On Time Off

> **17:59。**
>
> 包已经拉好拉链，工牌挂在手腕上，鼠标停在关机键上。
> 再数六十秒，走出这扇门，今天就是你的。
>
> 然后走廊拐角飘来一个声音——
>
> ## 「哎，小李，走这么急啊？」

**《按时下班》是一个 60 秒的俯视角潜行游戏。**

别的潜行游戏里，敌人是守卫、猎犬和红外线。这个游戏里，敌人是**端着咖啡的领导**和**抱着电脑的同事**。

🎮 **在线试玩**：<https://on-time-off.app.workbuddy.host/>　（手机直接点开，不用装任何东西）

---

## 这个世界的两条定律

开发之前，我们把办公楼里的恐惧清点了一遍。清到最后只剩下两条，删不掉、绕不开、每天准时出现：

> ### 定律一：领导总是在你快下班的时候开会。
>
> ### 定律二：同事总是在你快下班的时候有事。

不是概率事件，是恒定规律。

所以游戏里**没有随机刷怪、没有隐藏陷阱、没有阴间 debuff**——所有危险都摆在你眼前，只要你愿意抬头看一眼走廊。它不靠信息不对称制造紧张，它靠**你明知道他在那儿，但你就是得过去**。

现实里这两条定律你改不了。游戏里，你有 60 秒。

## 走廊上的四种人

| 谁 | 手里拿着什么 | 嘴里说着什么 |
|---|---|---|
| **你** | 已经拉好拉链的双肩包，两条背带跨在肩上 | —— |
| **同事 · 老王** | 一叠 A4，红色抬头 | 「正好有个事，两分钟。」 |
| **同事 · 小李** | 一台亮着屏幕的笔记本 | 「你等我一下，马上好。」 |
| **领导 · 陈总 / 张总** | 一杯还在冒热气的咖啡 | 「来我办公室一趟。」 |

他们的**视野锥就是他们的注意力**。焦点扫到哪儿，哪儿就是禁区。你能清清楚楚看见每个人的注意力落在哪——这是这个游戏唯一的"外挂"，也是它全部的公道。

---

## 但你不是一击必死

走进视野不会立刻完蛋。你头顶先冒出一个 `?`，然后 **`?` 慢慢涨成 `!`**。

这一秒多，就是你的逃命窗口：**退出视野，警觉条会以两倍速度回落**。

所以它考的不是手速，是**"什么时候该退一步"**。只有两种情况直接判负——警觉条涨满，或者凉透了直接撞到人身上。

然后你会听到那句话：

> 「哎小李，正好，帮我看个东西，两分钟。」
> 「今天走得挺早啊。」
> 「正好，这个方案我们再过一遍。」

被抓住的瞬间会弹出一张台词卡。我们刻意把它做得能截图——**被打断的那一刻，比通关更值得发出去。**

## 怎么玩

| 操作 | 手机 | 电脑 |
|---|---|---|
| 移动 | 左半屏拖动摇杆 | `W` `A` `S` `D` / 方向键 |
| 跑 | 右下角按住 | `Shift` |
| 重开 | 卡片上的按钮 | `R` |

**跑步是有代价的**：脚下会荡开一个噪音圈，附近的同事即使背对着你，也会慢慢起疑。

**家具挡视线也挡走位**——工位隔板、快递架、绿植、咖啡机，都是能藏的。

                              │ 门

                        ┌─────┴─────┐

每一段考的东西不一样：**工位区考时机，走廊考空间，茶水间考你敢不敢赌，电梯厅考速度**。

## 第 1 局是保送的（这是私心）

第 1 局只放一个同事，而且把他的视野压到 72%。第 2 局加领导，第 3 局才加走廊，第 4 局全员到齐。

原因很直白：**我们不想让你在第一次打开的时候就讨厌这个游戏。** 第 1 局的任务是教会你看视野锥，不是考住你。

| 局数 | 谁会来 | 视野系数 | 实测通关率 |
|---|---|---|---|
| 第 1 局 | 同事 · 老王 | 72% | **97%** |
| 第 2 局 | + 领导 · 陈总 | 85% | **73%** |
| 第 3 局 | + 同事 · 小李 | 94% | **23%** |
| 第 4 局起 | + 领导 · 张总 | 100% | **20%** |

看第 3 局那个断崖——**走廊是整张图唯一的墙**，它一个人贡献了全部难度。

## 实测数据

开发期间用无头 Chromium **直接驱动游戏自己的 `update()`** 跑过 120 局（不是另写模拟脚本，跑的就是真代码）。结论留在这儿，免得以后忘了当初为什么这么调：

- **最短路径 1220 px，纯走 13.9 秒。** 也就是说「距离下班还有 1 分钟」这个设定其实很宽裕——谨慎型玩家平均 15~19 秒就出去了，60 秒版通关后还剩 41~44 秒。开始页因此放了 `60 秒版` 和 `32 秒版` 两个按钮，后者才真的逼你在窗口前做取舍。
- **各闸门「存在安全站位」的时间占比 94%~100%。** 贴着墙走几乎永远安全。因为巡逻是静态的——**学会一次，就能一直用**。
- **全场平均等待只有 0.28 秒。** 玩家从来不"停下等时机"，只会"绕过去"。掩体给太多了。
- 120 局里 56 次失败，死因分布：走廊的同事 32 次、工位区的同事 12 次、超时 11 次、电梯厅的领导 1 次。

## 还没解决的

- **缺少"必须停下来等"的时刻。** 安全区太宽、掩体太多，玩法偏"绕路规划"而不是"掐时机"。下一步打算给 NPC 加**摸鱼状态**——他背过身接电话的时候，视野锥直接消失。让安全区动起来，才能逼出真正的心跳。
- 60 秒对当前这张图偏长，要么缩到 32 秒，要么把地图拉长到 1.5 倍。
- 失败台词卡的分享样式还没做。

## 结构

```
.
├── index.html      # 全部代码：几何、AI、判定、渲染、输入
└── 角色设定.png     # 角色设定图（用 10 倍放大核对过四个朝向）
```

纯前端单文件，**零依赖、零构建**。双击 `index.html` 就能玩。

`index.html` 大致按这个顺序组织：世界几何常量 → 玩家 / NPC 参数 → 工具函数（碰撞、视线、遮挡） → 状态 → 更新逻辑 → 判定 → 渲染（含 `drawPerson` 小人绘制） → 输入 → 主循环。

想自己调难度，改这四个地方就够了：

| 常量 | 管什么 |
|---|---|
| `NPC_DEFS` | 单个 NPC 的视野角度 / 距离 / 移动速度 / 察觉时间 |
| `ROUND_NPCS` | 每一局谁上场 |
| `ROUND_TUNING` | 每一局的整体难度系数 |
| `ROUND_TIME` | 单局秒数 |
