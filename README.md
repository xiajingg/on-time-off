# 按时下班 · On Time Off

> **17:59。**
>
> 包已经拉好拉链，工牌挂在手腕上，鼠标停在关机键上。
> 再数六十秒，走出这扇门，今天就是你的。
>
> 然后走廊拐角飘来一个声音——
>
> ## 「哎，小李，走这么急啊？」

**《按时下班》是一个 60 秒的俯视角潜行游戏。**

别的潜行游戏里，敌人是守卫、猎犬和红外线。这个游戏里，敌人是**端着咖啡的领导**和**抱着电脑的同事**。

🎮 **在线试玩**：<https://on-time-off.app.workbuddy.host/>　（手机直接点开，不用装任何东西）

---

## 这个世界的两条定律

开发之前，我们把办公楼里的恐惧清点了一遍。清到最后只剩下两条，删不掉、绕不开、每天准时出现：

> ### 定律一：领导总是在你快下班的时候开会。
>
> ### 定律二：同事总是在你快下班的时候有事。

不是概率事件，是恒定规律。

所以游戏里**没有随机刷怪、没有隐藏陷阱、没有阴间 debuff**——所有危险都摆在你眼前，只要你愿意抬头看一眼走廊。它不靠信息不对称制造紧张，它靠**你明知道他在那儿，但你就是得过去**。

现实里这两条定律你改不了。游戏里，你有 60 秒。

## 走廊上的五种人

| 谁 | 手里拿着什么 | 嘴里说着什么 |
|---|---|---|
| **你** | 已经拉好拉链的双肩包，两条背带跨在肩上 | —— |
| **同事 · 老王** | 一叠 A4，红色抬头 | 「正好有个事，两分钟。」 |
| **同事 · 小李** | 一台亮着屏幕的笔记本 | 「你等我一下，马上好。」 |
| **同事 · 老周** | 一叠 A4，塞在档案室柜子间 | 「你找什么呢？」 |
| **领导 · 陈总 / 张总** | 一杯还在冒热气的咖啡 | 「来我办公室一趟。」 |

他们的**视野锥就是他们的注意力**。焦点扫到哪儿，哪儿就是禁区。你能清清楚楚看见每个人的注意力落在哪——这是这个游戏唯一的"外挂"，也是它全部的公道。

---

## 他们不是巡逻的，是在上班

一开始 NPC 是两点往返的 —— 走出来就是个节拍器：走到头、停一下、走回来。看着不像人，像扫地机器人。

现在是**站点制**：每个人有一组「站点」，走到一站做一个动作，待一会儿，再随机挑下一站。所以路线每局都不一样。

| 状态 | 视野 | 画面上长什么样 | 对你意味着 |
|---|---|---|---|
| **走动中** | 100% | 正常走路，有起伏 | 危险，锥体横扫走廊 |
| **站着聊工作** | 85% | 头顶冒白色对话气泡，三个点在跳 | 局部危险，绕开他正面就行 |
| **坐下办公** | **40%** | 身后有椅子，屏幕往外溅蓝光 | **安全窗口** —— 他在盯屏幕，没在看你 |

这就是一直缺的那个东西：**一个可以等的时机。**

改之前全场平均等待只有 0.28 秒 —— 玩家从来不「停下等时机」，只会「换条路绕过去」。加了坐下办公之后涨到 **0.60 秒**，而且因为锥体长度是肉眼可见地变短，玩家能一眼读出「现在能过」。

顺带，行为分布实测是这样（90 秒采样）：

| 状态 | 占比 |
|---|---|
| 走动 | 28% |
| 坐下办公 | **42%** |
| 站着聊天 | 30% |

## 但你不是一击必死

走进视野不会立刻完蛋。你头顶先冒出一个 `?`，然后 **`?` 慢慢涨成 `!`**。

这一秒多，就是你的逃命窗口：**退出视野，警觉条会以两倍速度回落**。

所以它考的不是手速，是**"什么时候该退一步"**。只有两种情况直接判负——警觉条涨满，或者凉透了直接撞到人身上。

然后你会听到那句话：

> 「哎小李，正好，帮我看个东西，两分钟。」
> 「今天走得挺早啊。」
> 「正好，这个方案我们再过一遍。」

被抓住的瞬间会弹出一张台词卡。我们刻意把它做得能截图——**被打断的那一刻，比通关更值得发出去。**

---

## 以及一次「掀桌子」的机会

被叫住的那一刻，时间会停下来。对方说出台词，你手里有个键盘，有 **4 秒**决定。

| 你做什么 | 会发生什么 |
|---|---|
| **动手** | 键盘糊他脸上。他躺 **16 秒**起不来（视野锥直接消失），你继续走 —— 代价是扣 **8 秒** |
| **不动手** | 加班。老老实实重开 |

**每局只此一次。** 所以第一次犯错是可救的，第二次就是真的。

这条数值不是随手拍的：加上它之后，第 4 局的通关率从 **13% 涨到 38%** —— 原本那个数字太劝退，朋友第一次玩根本走不到电梯厅。而代价定在 8 秒，是因为它必须**真的疼**：不疼的话，「被抓」就不再是一件要避免的事，整个潜行也就白做了。

## 怎么玩

| 操作 | 手机 | 电脑 |
|---|---|---|
| 移动 | 左半屏拖动摇杆 | `W` `A` `S` `D` / 方向键 |
| 跑 | 右下角按住 | `Shift` |
| 重开 | 卡片上的按钮 | `R` |

**跑步是有代价的**：脚下会荡开一个噪音圈，附近的同事即使背对着你，也会慢慢起疑。

**家具挡视线也挡走位**——工位隔板、快递架、绿植、咖啡机，都是能藏的。

## 关卡：一块开放地板 + 一道道圆头墙

不是「房间 + 走廊」的方格子，而是迷宫那种做法：**整层是一块开放地板，墙是一条条圆头墙体**，
玩家在开放空间里绕墙走。

```
  ┌────────────────────────────────────────┐   打卡机
  │                电梯厅                   │
  │    ╭─────────────────────╮             │
  │ ╭──╯                     ╰──────────── │   北区
  │ │              ╭────────────────────╮  │
  │ ╰──────────────╯                    │  │   会议区
  │      ╭──────────────────────╮       │  │
  │ ╰────╯                      ╰───────╯  │   茶水间
  │ ╭───────────────╮     ╭──────────╮     │
  │ │               ╰─────╯          │     │   档案室 / 开放办公区
  │ ╰────────────────────────────────╯     │
  │              工位区（你在这里）          │
  └────────────────────────────────────────┘
```

**为什么墙是弯的**：视野是「正前方一条直线、能一眼看到底」（领导 400px，走廊里能看穿整条通道）。
一条笔直的走廊里他站一头就能看到另一头，玩家没有任何安全区。
**每弯一次，直线视线就被墙切断一次** —— 所以墙必须弯，这是机制逼出来的，不是美术选择。

**为什么不该更复杂**：六道主墙交替从左右伸出，形成一条 S 形通路（六次换边），
其中两处留了额外缺口。有分岔、要判断，但不会绕晕。

## 难度阶梯

**原本前两局是「保送局」**（只放一个同事、视野压到 60%），实测通关率 94%。后来砍掉了 —— 玩起来像教程，不像游戏。

现在第 1 局就是「西走廊 + 漏斗口」，三关递进：

| 局数 | 谁会来 | 视野系数 | 通关率（会用掀桌子） |
|---|---|---|---|
| 第 1 局 | 老王（工位区）+ 小李（西走廊）+ 陈总（漏斗口） | 94% | **69%** |
| 第 2 局 | + 张总（东走廊） | 90% | **63%** |
| 第 3 局起 | + 老周（档案室） | 96% | **56%** |

这里有个值得记下来的取舍：我一开始很坚持「首局保送」，理由是别让玩家第一次打开就讨厌这个游戏。但实测 94% 的通关率对玩家**没有价值** —— 它不是「宽容」，是「没有挑战」。

真正需要被保送的不是「第一局」，而是**「第一次失误」**。这件事现在由「掀桌子」承担了：同样是不让一次手滑就结束，但它发生在紧张的瞬间，而不是把整局变简单。

## 实测数据

开发期间用无头 Chromium **直接驱动游戏自己的 `update()`** 跑批量对局（不是另写模拟脚本，跑的就是真代码）。结论留在这儿，免得以后忘了当初为什么这么调：

- **最短路径 1452 px（纯走 16.5 秒）。** 谨慎型玩家实际要 29~32 秒 —— 多出来的十几秒全是绕路和等窗口。
- **「加房间」解决不了「只会绕、不会等」。** 把地图从 4 间扩到 7 间，平均等待只从 0.28 秒涨到 0.36 秒，几乎没动。真正起作用的是**给 NPC 加「坐下办公」**：同一个动作把等待推到 **0.60 秒**。

  这一条是立项到现在最值钱的一课：**让安全区动起来，比让它变窄有用得多。** 前者制造的是「等一个时机」，后者制造的只是「多绕两步」。

- **各闸门「存在安全站位」的时间占比仍在 90% 以上** —— 只要 NPC 在走动，贴墙走几乎永远安全，因为巡逻是静态的。所以威胁不能只靠空间，得靠**时间上的窗口**（坐下办公那 42% 的时间）。
- **加了「掀桌子」之后，最难那两局的通关率从 13% 提到 38~50%。** 这条机制的定位不是「送一条命」，而是「把一次性失误的代价从『重开』降级成『扣 8 秒』」。
- 48 局实测的难度阶梯：**69% → 50% → 63%**（每局 16 次，机器人会看视野锥、会绕路、被抓就掀桌子。样本小，第 2、3 局之间的差在噪声范围内）。
- 行为分布（90 秒采样）：走动 28% / 坐下办公 42% / 站着聊天 30%。

## 还没解决的

- **姿态只有两种**（站着聊 / 坐下办公）。还想加「打电话」（背对全场，视野锥直接消失十几秒）和「去会议室」（消失更久，但回来时会带一个人）。
- **60 秒的定位还没定下来。** 通关中位数 30 秒，成功局还剩 23~27 秒 —— 说它是压力，余量太大；说它是装饰，又有 23% 的局真的超时。要么缩到 45 秒，要么就明确它只是个上限。
- 失败台词卡的分享样式还没做。

## 结构

```
.
├── index.html      # 全部代码：几何、AI、判定、渲染、输入
├── 关卡地图.png     # 关卡全貌（含五个 NPC 的视野锥）
├── 掀桌子-选择.png   # 被抓瞬间：4 秒决定要不要抄键盘
├── 掀桌子-出手.png   # 命中：对方倒地
└── 角色设定.png     # 角色设定图（用 10 倍放大核对过四个朝向）
```

纯前端单文件，**零依赖、零构建**。双击 `index.html` 就能玩。

`index.html` 大致按这个顺序组织：世界几何常量 → 玩家 / NPC 参数 → 工具函数（碰撞、视线、遮挡） → 状态 → 更新逻辑 → 判定 → 渲染（含 `drawPerson` 小人绘制） → 输入 → 主循环。

想自己调难度，改这四个地方就够了：

| 常量 | 管什么 |
|---|---|
| `NPC_DEFS` | 单个 NPC 的视野角度 / 距离 / 移动速度 / 察觉时间 |
| `ROUND_NPCS` | 每一局谁上场 |
| `ROUND_TUNING` | 每一局的整体难度系数 |
| `ROUND_TIME` | 单局秒数 |
