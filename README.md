# 按时下班 · On Time Off

一个 60 秒的俯视角潜行小游戏。18:00 还差 1 分钟，你要从工位走到打卡机，**别被任何同事或领导看见**——被看见就要加班。

> 🎮 在线试玩：<https://on-time-off.app.workbuddy.host/>

纯前端单文件，零依赖零构建。双击 `index.html` 就能玩。

---

## 玩法

| 操作 | 手机 | 电脑 |
|---|---|---|
| 移动 | 左半屏拖动摇杆 | `W` `A` `S` `D` / 方向键 |
| 跑 | 右下角按住 | `Shift` |
| 重开 | 卡片按钮 | `R` |

**判定规则**：身体进入视野锥 → 头顶冒 `?`，警觉条开始累积；**走出锥体后警觉条以 2 倍速回落**，所以被发现还有机会救回来。警觉条满、或者直接撞到人 → 当场加班。

跑步会产生噪音圈，附近的 NPC 即使背对着你也会慢慢起疑。家具挡视线也挡走位，可以用来藏。

### 难度阶梯（首局保送）

局数越多，NPC 的视野 / 移动速度 / 察觉速度越强，同时上场的人数也递增：

| 局数 | NPC | 视野系数 | 实测通关率 |
|---|---|---|---|
| 第 1 局 | 同事 · 老王 | 72% | 97% |
| 第 2 局 | + 领导 · 陈总 | 85% | 73% |
| 第 3 局 | + 同事 · 小李 | 94% | 23% |
| 第 4 局起 | + 领导 · 张总 | 100% | 20% |

第 1 局刻意压到 72% 视野，是为了**先教会玩家看视野锥**，而不是先考住他。

### 角色

| 角色 | 形象 | 行为 |
|---|---|---|
| 你 | 背着深蓝双肩包、两条背带跨肩 | 玩家 |
| 同事 · 老王 | 右手夹着一叠 A4 文件 | 工位区横向巡逻 |
| 同事 · 小李 | 双手抱着笔记本电脑 | 走廊纵向巡逻 |
| 领导 · 张总 / 陈总 | 端着纸杯咖啡、灰白头发 | 茶水间 / 电梯厅 |

角色是俯视角绘制的：**看到的是「肩 + 头顶」**，所以头是「大半头发 + 前缘一弯脸」，而不是正面脸的圆。

## 实测数据

开发期间用无头 Chromium 直接驱动游戏自己的 `update()` 跑过批量对局（不是模拟脚本，是真代码）。结论记录在这里，免得后面忘了当初为什么这么调：

- **最短路径 1220 px = 纯走 13.9 秒**。所以「距离下班还有 1 分钟」这个设定其实很宽裕——谨慎型玩家平均 15~19 秒通关，60 秒版通关后还剩 41~44 秒。开始页因此放了 `60 秒版` 和 `32 秒版` 两个按钮，后者才真的逼你在窗口前做取舍。
- **各闸门「存在安全站位」的时间占比 94%~100%**。贴着墙走几乎永远安全——巡逻是静态的，学会一次就能一直用。
- **全场平均等待时间只有 0.28 秒**。玩家从来不「停下等时机」，只会「绕过去」。掩体给太多了。
- 120 局里 56 次失败，死因分布：走廊的同事 32 次、工位区的同事 12 次、超时 11 次、电梯厅的领导 1 次。**走廊那一关贡献了全部难度。**

### 还没解决的

- **缺少「必须停下来等」的时刻**。安全区太宽、掩体太多，玩法偏「绕路规划」而不是「掐时机」。下一步打算给 NPC 加**摸鱼状态**（背对你打电话时视野锥消失），让安全区动起来。
- 60 秒对当前这张地图偏长，要么缩到 32 秒，要么把地图拉长到 1.5 倍。
- 失败台词卡还没做成可截图分享的样式。

## 结构

```
.
├── index.html      # 全部代码：几何、AI、判定、渲染、输入
└── 角色设定.png     # 角色设定图（用 10 倍放大核对过朝向）
```

`index.html` 里大致按这个顺序组织：世界几何常量 → 玩家 / NPC 参数 → 工具函数（碰撞、视线、遮挡） → 状态 → 更新逻辑 → 判定 → 渲染（含 `drawPerson` 小人绘制） → 输入 → 主循环。

想调难度直接改 `NPC_DEFS`（单个 NPC 的视野 / 速度 / 察觉时间）、`ROUND_NPCS`（每局上场谁）、`ROUND_TUNING`（每局的难度系数）、`ROUND_TIME`（单局秒数）。
