# 按时下班 · On Time Off

> **17:59。**
>
> 包已经拉好拉链，工牌挂在手腕上，鼠标停在关机键上。
> 再数六十秒，走出这扇门，今天就是你的。
>
> 然后走廊拐角飘来一个声音——
>
> ## 「哎，小李，走这么急啊？」

**《按时下班》是一个 60 秒的俯视角潜行游戏。**

别的潜行游戏里，敌人是守卫、猎犬和红外线。这个游戏里，敌人是**端着咖啡的领导**和**抱着电脑的同事**。

🎮 **在线试玩**：<https://on-time-off.app.workbuddy.host/>　（手机直接点开，不用装任何东西）

---

## 这个世界的两条定律

开发之前，我们把办公楼里的恐惧清点了一遍。清到最后只剩下两条，删不掉、绕不开、每天准时出现：

> ### 定律一：领导总是在你快下班的时候开会。
>
> ### 定律二：同事总是在你快下班的时候有事。

不是概率事件，是恒定规律。

所以游戏里**没有随机刷怪、没有隐藏陷阱、没有阴间 debuff**——所有危险都摆在你眼前，只要你愿意抬头看一眼走廊。它不靠信息不对称制造紧张，它靠**你明知道他在那儿，但你就是得过去**。

现实里这两条定律你改不了。游戏里，你有 60 秒。

## 走廊上的五种人

| 谁 | 手里拿着什么 | 嘴里说着什么 |
|---|---|---|
| **你** | 已经拉好拉链的双肩包，两条背带跨在肩上 | —— |
| **同事 · 老王** | 一叠 A4，红色抬头 | 「正好有个事，两分钟。」 |
| **同事 · 小李** | 一台亮着屏幕的笔记本 | 「你等我一下，马上好。」 |
| **同事 · 老周** | 一叠 A4，塞在档案室柜子间 | 「你找什么呢？」 |
| **领导 · 陈总 / 张总** | 一杯还在冒热气的咖啡 | 「来我办公室一趟。」 |

他们的**视野锥就是他们的注意力**。焦点扫到哪儿，哪儿就是禁区。你能清清楚楚看见每个人的注意力落在哪——这是这个游戏唯一的"外挂"，也是它全部的公道。

## 但你不是一击必死

走进视野不会立刻完蛋。你头顶先冒出一个 `?`，然后 **`?` 慢慢涨成 `!`**。

这一秒多，就是你的逃命窗口：**退出视野，警觉条会以两倍速度回落**。

所以它考的不是手速，是**"什么时候该退一步"**。只有两种情况直接判负——警觉条涨满，或者凉透了直接撞到人身上。

然后你会听到那句话：

> 「哎小李，正好，帮我看个东西，两分钟。」
> 「今天走得挺早啊。」
> 「正好，这个方案我们再过一遍。」

被抓住的瞬间会弹出一张台词卡。我们刻意把它做得能截图——**被打断的那一刻，比通关更值得发出去。**

---

## 以及一次「掀桌子」的机会

被叫住的那一刻，时间会停下来。对方说出台词，你手里有个键盘，有 **4 秒**决定。

| 你做什么 | 会发生什么 |
|---|---|
| **动手** | 键盘糊他脸上。他躺 **16 秒**起不来（视野锥直接消失），你继续走 —— 代价是扣 **8 秒** |
| **不动手** | 加班。老老实实重开 |

**每局只此一次。** 所以第一次犯错是可救的，第二次就是真的。

这条数值不是随手拍的：加上它之后，第 4 局的通关率从 **13% 涨到 38%** —— 原本那个数字太劝退，朋友第一次玩根本走不到电梯厅。而代价定在 8 秒，是因为它必须**真的疼**：不疼的话，「被抓」就不再是一件要避免的事，整个潜行也就白做了。

## 怎么玩

| 操作 | 手机 | 电脑 |
|---|---|---|
| 移动 | 左半屏拖动摇杆 | `W` `A` `S` `D` / 方向键 |
| 跑 | 右下角按住 | `Shift` |
| 重开 | 卡片上的按钮 | `R` |

**跑步是有代价的**：脚下会荡开一个噪音圈，附近的同事即使背对着你，也会慢慢起疑。

**家具挡视线也挡走位**——工位隔板、快递架、绿植、咖啡机，都是能藏的。

## 关卡：七个房间，三条通道，一个漏斗

```
  ┌─────────────────── 电梯厅 ───────────────────┐  ← 打卡机
  ├──────┬────────────────────────┬─────────────┤
  │      │      开放办公区         │             │  领导·陈总 堵在向上唯一的漏斗口
  │  西  ├────────────────────────┤  东         │
  │  走  │       茶水间            │  走         │  西：同事·小李
  │  廊  ├────────────────────────┤  廊         │  东：领导·张总
  │      │       档案室            │             │  同事·老周
  ├──────┴────────────────────────┴─────────────┤
  │                   工位区                     │  同事·老王
  │                      你 ↑                    │
  └──────────────────────────────────────────────┘
        出口↑        出口↑        出口↑
```

**关键结构**：中间三间（开放办公区 / 茶水间 / 档案室）**彼此之间没有门**。想纵向移动，只能走西走廊或东走廊 —— 这是你每局的第一次取舍。而往上最后只能穿过「开放办公区」进电梯厅，那是唯一的漏斗口。

所以这张图是这么读的：

- 底部 **三个出口**（西走廊 / 档案室 / 东走廊）
- 中段 **三条通道**（西走廊 / 中间三间 / 东走廊），但中间那条是**断的**
- 顶部 **一个入口**（只能经开放办公区）

走西走廊还是东走廊，是你每局要做的第一个决定；**而且两条路各有人守。**

## 第 1 局是保送的（这是私心）

第 1 局只放一个同事，而且把他的视野压到 72%。第 2 局加领导，第 3 局才加走廊，第 4 局全员到齐。

原因很直白：**我们不想让你在第一次打开的时候就讨厌这个游戏。** 第 1 局的任务是教会你看视野锥，不是考住你。

| 局数 | 谁会来 | 视野系数 | 通关率（会用掀桌子） |
|---|---|---|---|
| 第 1 局 | 同事 · 老王 | 60% | **94%** |
| 第 2 局 | + 领导 · 陈总（漏斗口） | 85% | **94%** |
| 第 3 局 | + 同事 · 小李（西走廊） | 94% | **63%** |
| 第 4 局 | + 领导 · 张总（东走廊） | 90% | **38%** |
| 第 5 局起 | + 同事 · 老周（档案室） | 96% | **50%** |

前两局是保送，第 3 局开始真正咬人，第 4 局两条走廊同时有人守 —— **那才是这张图真正的墙**。80 局里 27 局动过手，说明这个按钮不是摆设。

## 实测数据

开发期间用无头 Chromium **直接驱动游戏自己的 `update()`** 跑过 120 局（不是另写模拟脚本，跑的就是真代码）。结论留在这儿，免得以后忘了当初为什么这么调：

- **地图翻新后最短路径 1452 px（纯走 16.5 秒）**，旧图是 1220 px（13.9 秒）。可行走面积从 466k 涨到 563k px²。谨慎型玩家实际要 19~26 秒 —— 但 60 秒版通关后**仍然剩 33~41 秒**。开始页因此保留 `60 秒版` 和 `32 秒版` 两个按钮。
- **各闸门「存在安全站位」的时间占比仍在 90% 以上。** 贴着墙走几乎永远安全，因为巡逻是静态的 —— **学会一次，就能一直用**。
- **全场平均等待只有 0.36 秒。** 把地图从 4 间扩到 7 间之后，这个数字只从 0.28 涨到 0.36，几乎没动。这说明了「加房间」解决不了这个问题：玩家从来不停下等时机，只会换条路绕过去。
- **加了「掀桌子」之后，第 4/5 局的通关率从 13% 提到 38~50%。** 这条机制的定位不是「送一条命」，而是「把一次性失误的代价从『重开』降级成『扣 8 秒』」——对传播型小游戏来说，前者会让人关掉页面，后者会让人再来一把。
- 80 局实测的难度阶梯：**94% → 94% → 63% → 38% → 50%**（每局 16 次，机器人会看视野锥、会绕路、被抓就掀桌子）。

## 还没解决的

- **缺少必须停下来等的时刻。** 这仍然是最核心的问题，而且扩图之后被证明了：安全区太宽、掩体太多、路太多，玩家永远能绕。下一步要做的不是继续加房间，而是给 NPC 加**摸鱼状态** —— 他背过身接电话的时候视野锥直接消失。让安全区**动起来**而不是**变窄**，才能逼出真正的心跳。
- 60 秒对当前这张图仍然偏长（通关平均 19~26 秒），要么缩到 40 秒，要么接受它只是个上限而不是压力。
- 失败台词卡的分享样式还没做。

## 结构

```
.
├── index.html      # 全部代码：几何、AI、判定、渲染、输入
├── 关卡地图.png     # 关卡全貌（含五个 NPC 的视野锥）
├── 掀桌子-选择.png   # 被抓瞬间：4 秒决定要不要抄键盘
├── 掀桌子-出手.png   # 命中：对方倒地
└── 角色设定.png     # 角色设定图（用 10 倍放大核对过四个朝向）
```

纯前端单文件，**零依赖、零构建**。双击 `index.html` 就能玩。

`index.html` 大致按这个顺序组织：世界几何常量 → 玩家 / NPC 参数 → 工具函数（碰撞、视线、遮挡） → 状态 → 更新逻辑 → 判定 → 渲染（含 `drawPerson` 小人绘制） → 输入 → 主循环。

想自己调难度，改这四个地方就够了：

| 常量 | 管什么 |
|---|---|
| `NPC_DEFS` | 单个 NPC 的视野角度 / 距离 / 移动速度 / 察觉时间 |
| `ROUND_NPCS` | 每一局谁上场 |
| `ROUND_TUNING` | 每一局的整体难度系数 |
| `ROUND_TIME` | 单局秒数 |
